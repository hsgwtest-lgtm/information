# Pocket CAD Pro 要件定義

無料版 [Pocket CAD](../pocket-cad/) の全機能に、3D プリントの「設計 → 最適化 → 印刷準備 → 出力」を
大きく短縮する機能を加えたもの。**全機能を登録・課金なしで使える**（v1.2 で有料プラン・ライセンスキーを廃止）。

## 1. 想定ユーザーの課題 → 解決

| 課題 | 解決策 | 時間・費用の目安 |
| --- | --- | --- |
| ブラケットや受けを、どこまで肉抜きしてよいか分からない | トポロジー最適化で、固定と荷重から必要な所だけを残した形を自動生成。重さ・たわみ・応力の目安つき | 試作の繰り返し → 1 回の計算（数秒〜数十秒） |
| どの向きで印刷すればサポートが少ないか分からない | 数十通りの置き方を比較し、サポート量・時間・接地面積で候補を提示 | 失敗 1 回分のフィラメントと数時間を節約 |
| 1 枚のプレートに何個入るか分からない・並べるのが面倒 | 実際の形で詰める自動配置と、入るだけ並べる敷き詰め | 手作業の配置が不要。販売用の量産に直結 |
| ねじのモデリングは難しく、出先ではまず無理 | ISO メートルねじ（M2〜M20）のボルト・ナット・ねじ穴をワンタップ生成。公差指定付き | 1 部品あたり数十分 → 数秒 |
| 歯車は計算が面倒 | モジュール・歯数を入れるだけでインボリュート平歯車 | 計算・作図 1 時間 → 数秒 |
| 基板や小物のケースを毎回ゼロから作る | 内寸を入れると本体＋はめ込みフタを自動生成 | 30 分以上 → 1 分 |
| 日本語の名札・プレートが作れない | 端末のフォント（ヒラギノ）で日本語を立体化 | 他ソフトで作成 → その場で完結 |
| ロゴや手描きを立体にしたい | PNG / JPG / SVG の輪郭抽出→押し出し、写真からリトフェイン | PC 作業 → iPhone だけで完結 |
| 印刷時間・材料費が分からない | 積層・充填・単価から時間／重量／費用を見積もり | 受託・販売時の見積もりに直結 |
| マルチカラー機で色ごとに分けたい | 3MF（パーツ・色情報付き）/ OBJ 出力 | スライサーでの再割り当てが不要 |
| 変更前の形に戻したい | バージョン履歴（出力時は自動保存） | 作り直しを防止 |
| 何を作るか決まっているのに一から作図が面倒 | 実用品テンプレート 9 種（Gridfinity 互換ビンほか）を寸法入力だけで生成 | 作図 30 分〜 → 1 分 |
| 造形エリアより大きい物が作れない | ダボ（位置合わせピン）付きで自動分割 | 手作業の分割・穴合わせが不要 |
| 外注・打ち合わせ用の図面がない | 寸法・隠れ線入りの三面図を A4 SVG で出力 | 別の CAD で図面化する手間を削減 |
| 似た部品を何度も作る | マイパーツで再利用、変数で寸法を一括変更 | 設計変更が 1 か所の修正で済む |
| 人にデータを渡したい | 共有リンク | ファイルのやり取りが不要 |
| 角を丸めたい・付け根を補強したい | 辺をタップで選んでフィレット / 面取り（へこんだ辺は肉盛り）。大きさは後から変更 | 形を作り直す手間が不要 |
| 箱の高さを変えたい・面を少しへこませたい | 平らな面を選んで押し出し / へこませ | 寸法の計算・作り直しが不要 |
| 中身の詰まった形を容器にしたい・材料を減らしたい | シェル（開ける面を選んで中空化） | 材料・時間を大きく削減 |
| 軽く見栄えのする形にしたい | ボロノイ・ジャイロイドの格子化（重さをプレビューで確認） | 専用ソフトが不要 |
| サポートを付けずに印刷したい | 横穴のティアドロップ化、張り出しの 45° 補強、底の面取りを自動で追加 | サポート除去の手間と跡がなくなる |
| 手元の物にぴったりの入れ物を作りたい | A4 の紙に置いて撮るだけで実寸の輪郭を取り、トレー・型板を作成 | ノギスでの採寸・作図が不要 |
| はめ込み式のフタや留め具が割れる | 材料ごとの許容ひずみでスナップフィットを設計（力の目安つき） | 試し刷りの繰り返しを削減 |
| 動く部品を組み立てずに作りたい | そのまま動く蝶番のテンプレート | 組み立て・ピン不要 |

## 2. 機能要件（無料版に追加）

### 2.1 最適化
- 形状の最適化（トポロジー最適化）
  - 設計領域（幅・高さ・厚み）、残す材料の割合（10〜80%）、計算の細かさ（約 2,400 / 4,800 / 8,000 要素）
  - 固定: ネジ穴・支点（穴径・周りの肉厚、全方向 / 上下のみ / 左右のみ）、辺全体
  - 荷重: 点（穴あり / なし、向き・大きさ N。穴の場合はピンが押す側に分布）、辺全体の分布荷重（辺に沿って薄い面を残す）
  - 禁止範囲（材料を置かない四角形）
  - テンプレート 4 種（壁ブラケット・棚受け・橋（両端支持）・片持ち梁）
  - 荷重が 2 つ以上のとき「別々に考える」（荷重ケースを分けて、どれにも耐える形）
  - 編集: タップで追加、ドラッグで移動、辺のタップで辺の条件、数値入力（位置・寸法・向き・力）
  - 計算は Web Worker（使えない環境ではメインスレッド）で実行し、途中経過をリアルタイム表示。途中で止めた形も作成可
  - 支えが足りず部品が回転・移動できる条件はエラーで知らせる。形が分かれた場合は注意を表示
  - 結果: 重さ（板のままとの比較）、荷重点のたわみ（板のままとの比較）、応力の目安（上位 2%、材料の強さとの比）、応力分布の色表示
  - 作成される部品: 輪郭の押し出し＋正確な円柱のボス・穴のグループ（後から編集可）。条件を部品に保存し「再最適化」で置き換え可
- 向きの最適化
  - 候補: 現在の向き、大きな平面を下にする向き（最大 16）、6 方向、球面上に均等な 60 方向（約 4° 以内の重複は除く）
  - 指標: サポート体積（レイキャストで、部品の上に立つサポートは下の面までの高さで計算）、印刷時間（見積もり設定＋サポート材）、接地面積、高さ
  - 優先: おまかせ / サポート減 / 時短 / 安定。サポートなしで印刷できる角度 45〜60°
  - 候補 3 つ＋現在の向きを、サポートが必要な面を赤くしたプレビュー付きで表示。タップで適用し床に置く。
    傾けた場合は設置面積の外接長方形が最小になる向きに水平回転
- 自動配置（詰め込み）・敷き詰め
  - 上から見た形のラスター（約 1 mm）を部品間隔の半分だけ太らせ、重ならない位置に配置
  - 回転: なし / 90° ごと / 45° ごと（＋外接長方形が最小の向き）
  - 全部品（全体の外接長方形を小さく保ち、中央へ）/ 選択中だけ（他の部品は障害物）/ 敷き詰め（最大個数指定、空きに左手前から）
  - 配置図と使用率を事前に表示。入りきらない部品は造形エリアの外に並べて通知

### 2.2 設計
- ボルト（六角 / キャップ / 頭なし）・ナット・ねじ穴。サイズ M2〜M20、ねじ長さ、半径方向の公差、端部処理
- インボリュート平歯車（モジュール、歯数、厚み、軸穴、バックラッシ）。かみ合い距離の案内付き
- ケース自動設計（内寸、壁厚、角 R、フタの差し込み深さ、はめあいすき間）。結果は通常のグループなので後から編集可能
- 日本語テキスト（ゴシック / 明朝 / 丸ゴシック、太字、複数行）。後から文字を再編集可能
- 画像（PNG / JPG）の輪郭抽出（しきい値・反転）と SVG（塗りつぶし図形）の押し出し
- リトフェイン（幅、最小 / 最大厚、枠、反転）
- テンプレート 10 種: Gridfinity 互換ビン（マス数・高さ・仕切り・磁石穴）、小物トレイ、スマホスタンド、
  植木鉢、名札・プレート（日本語）、ケーブルクリップ、壁掛けフック（皿ネジ穴）、ハニカムコースター、ペン立て、
  蝶番（そのまま動く: 長さ・羽根の幅・板厚・軸の太さ・こまの数（奇数）・すき間・取付穴。こま同士は 45° の
  円すいピンとそのくぼみでつながり、どの面もサポートなしで印刷できる）
- スナップフィット設計（v1.3）
  - 片持ちばり（一定厚の長方形断面）の式で、ひずみ ε = 1.5·t·y / L²、たわませる力 P = b·t²·E·ε / (6L)、
    はめる力 W = P(μ + tan α) / (1 − μ tan α)、外す力（抜け角 β）を計算
  - 材料（設定の材料）ごとのヤング率・許容ひずみ（一度だけ / 何度も外す）・摩擦係数で判定。超える場合は必要な腕の長さを提案
  - フック（根元 R 付き、寝かせて印刷する向き）と受けの窓（すき間 0.25 mm）を作成
- 写真で採寸（v1.3）
  - 紙（A4 / B5 / A5 / レター / はがき）の 4 隅を自動検出（大津の二値化 → 最大の明るい領域 → 凸包 → 面積最大の四角形）。
    手で隅を動かして修正可
  - 射影変換（4 点の DLT）で 1 mm = 3 画素に補正し、紙の色との差で物を抽出（しきい値は自動 / 手動）
  - 作るもの: ぴったりトレー（すき間・深さ・底厚・余白、物ごとに指の切り欠き）/ 型板（切り抜いた板）/ 輪郭の形
- 面取り箱（角 R、上下の面取り）
- 変数による寸法駆動（寸法・位置の入力欄に変数を含む式を書ける。変数変更で一括再計算）
- マイパーツ（全プロジェクト共通の部品ライブラリ）

### 2.3 加工
- 分割（X / Y / Z、位置指定、ダボ穴とダボを自動生成。断面が細い場合はダボを省略して通知）
- パターン穴あけ（ハニカム / 丸 / 角、リブ幅・縁の余白、貫通 / 深さ指定。部品の形に沿って配置）
- 面に配置（タップした面の向きに合わせて部品を回転・移動）
- 辺・面の選択（v1.3）
  - ブーリアンの結果やテンプレートを含む任意の部品で、辺（折れ目 30° 以上。なめらかに続く辺は 1 本）と平らな面をタップで選択。
    隠れた辺は選ばない。選択中は部品が動かず、ドラッグは視点の回転
  - 辺: 丸め（フィレット R）/ 面取り（C）。出っ張った辺は削り、へこんだ辺は肉盛り。3 本の辺が直角に集まる角は球面で、
    出っ張った 2 本がへこんだ辺のまわりで曲がる内側の角（L 字の入隅）は断面を回してつなぐ。
    面の幅から上限を計算して表示・制限。結果はグループで、パネルから大きさを変更、「解除」で元に戻せる
  - 面: 押し出し / へこませ（距離指定、穴のあいた面は穴ごと）
  - シェル: 壁の厚み・細かさを指定して中空化。選んだ面は開口。外側は元の形のまま（内側の立体を引くグループ）
- 格子化（v1.3）
  - 表面ボロノイ（網目の殻: セル・線の太さ・網の厚み）、立体ボロノイ（骨組み: 表面の網あり / なし）、
    ジャイロイド（壁の厚み・外皮の厚み）。模様の番号で種点を変更、細かさ 3 段階
  - プレビュー（重さの変化・三角形数・時間、多すぎる場合は警告）。浮いた小片は除去
  - 部品は格子メッシュに置き換わり、元の形を保存して「格子の設定を変える」で作り直せる

### 2.4 印刷準備
- プリンター別プロファイル（Bambu Lab / Prusa / Creality / Elegoo / AnkerMake の主要機種）
- オーバーハング表示（45° 超の下向き面を赤表示、面積表示、編集に追従）
- 断面表示（X / Y / Z、スライダーで位置調整）
- 2 点間計測（頂点スナップ、XYZ 各成分）
- 印刷見積もり（時間・フィラメント g / m・材料費）
- サポートレス化（v1.3。今の向きで判定）
  - 横向きの丸穴・ねじ穴の天井を 45° にとがらせる（ティアドロップ）
  - 張り出し（下向きの面）と下の壁の角を 45° より少し急な斜面で埋める
  - 床に接する辺の面取り（エレファントフット対策、大きさ指定）
  - 適用前後のサポートが必要な面積を表示

### 2.5 出力・共有・管理
- 三面図（第三角法、平面図・正面図・右側面図、隠れ線は破線、外形寸法、尺度自動、表題欄、A4 横 SVG）
- 共有リンク（プロジェクトを圧縮して URL に格納。読み込んだ STL は含まない）
- 3MF（パーツごと・色付き、ZIP 圧縮）/ OBJ 出力
- バージョン履歴（手動保存・出力時の自動保存・復元・最大 50 件）
- 無料版プロジェクトの取り込み（同じ端末の無料版データを読み取り専用で参照）

## 3. 非機能要件
- 無料版と同じ（オフライン動作、iPhone 片手操作、セーフエリア対応など）
- 重い計算（トポロジー最適化・格子化・シェル）は Worker で行い操作を止めない。標準の細かさで数秒〜十数秒を目安とする
- 無料版と同じオリジンでも干渉しない（IndexedDB 名・localStorage 接頭辞・キャッシュ名を分離）

## 4. 今回の対象外 / 今後の候補
- 立体（3D）のトポロジー最適化（現在は板状の形を押し出す 2.5 次元）
- 分割位置の自動提案
- ねじのインチ規格、はすば歯車
- 辺の丸めで、直角でない角や、丸める辺が 2 本だけ出っ張った角で集まる所のなめらかなつなぎ（現在は辺どうしの交わりのまま）
- 曲面（円柱の側面など）の押し出し
- クラウド同期・チーム共有
