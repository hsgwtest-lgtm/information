# Pocket CAD Pro 要件定義

無料版 [Pocket CAD](../pocket-cad/) の全機能に、3D プリントの「設計 → 印刷準備 → 出力」を
大きく短縮する機能を加えた有料版。**月額 9,900 円（税込）**、14 日間の無料トライアル付き。

## 1. 価格に見合う価値（想定ユーザーの課題 → 解決）

| 課題 | Pro の解決策 | 時間・費用の目安 |
| --- | --- | --- |
| ねじ山のモデリングは難しく、出先ではまず無理 | ISO メートルねじ（M2〜M20）のボルト・ナット・ねじ穴をワンタップ生成。公差指定付き | 1 部品あたり数十分 → 数秒 |
| 歯車は計算が面倒 | モジュール・歯数を入れるだけでインボリュート平歯車 | 計算・作図 1 時間 → 数秒 |
| 基板や小物のケースを毎回ゼロから作る | 内寸を入れると本体＋はめ込みフタを自動生成 | 30 分以上 → 1 分 |
| 日本語の名札・プレートが作れない | 端末のフォント（ヒラギノ）で日本語を立体化 | 他ソフトで作成 → その場で完結 |
| ロゴや手描きを立体にしたい | PNG / JPG / SVG の輪郭抽出→押し出し、写真からリトフェイン | PC 作業 → iPhone だけで完結 |
| 印刷してからサポート不足・失敗に気づく | オーバーハング解析と自動向き最適化 | 失敗 1 回分のフィラメントと数時間を節約 |
| 印刷時間・材料費が分からない | 積層・充填・単価から時間／重量／費用を見積もり | 受託・販売時の見積もりに直結 |
| マルチカラー機で色ごとに分けたい | 3MF（パーツ・色情報付き）/ OBJ 出力 | スライサーでの再割り当てが不要 |
| 変更前の形に戻したい | バージョン履歴（出力時は自動保存） | 作り直しを防止 |

## 2. 機能要件（無料版に追加）

### 2.1 設計
- ボルト（六角 / キャップ / 頭なし）・ナット・ねじ穴。サイズ M2〜M20、ねじ長さ、半径方向の公差、端部処理
- インボリュート平歯車（モジュール、歯数、厚み、軸穴、バックラッシ）。かみ合い距離の案内付き
- ケース自動設計（内寸、壁厚、角 R、フタの差し込み深さ、はめあいすき間）。結果は通常のグループなので後から編集可能
- 日本語テキスト（ゴシック / 明朝 / 丸ゴシック、太字、複数行）。後から文字を再編集可能
- 画像（PNG / JPG）の輪郭抽出（しきい値・反転）と SVG（塗りつぶし図形）の押し出し
- リトフェイン（幅、最小 / 最大厚、枠、反転）

### 2.2 印刷準備
- オーバーハング表示（45° 超の下向き面を赤表示、面積表示、編集に追従）
- 自動向き最適化（24 通りの置き方から、サポート量・接地面積・高さで評価）
- 断面表示（X / Y / Z、スライダーで位置調整）
- 2 点間計測（頂点スナップ、XYZ 各成分）
- 自動配置（造形エリアに棚詰め）
- 印刷見積もり（時間・フィラメント g / m・材料費）

### 2.3 出力・管理
- 3MF（パーツごと・色付き、ZIP 圧縮）/ OBJ 出力
- バージョン履歴（手動保存・出力時の自動保存・復元・最大 50 件）
- 無料版プロジェクトの取り込み（同じ端末の無料版データを読み取り専用で参照）

## 3. プランと課金

| 状態 | 条件 | 使える機能 |
| --- | --- | --- |
| フリー | 初期状態 | 無料版と同じ（Pro 機能はプラン画面を表示） |
| トライアル | 「14日間無料で試す」を押してから 14 日 | すべて |
| Pro | 有効なライセンスキーを入力 | すべて（キーの有効期限まで） |

- 期限が切れても、作成済みのデータの閲覧・編集・STL 出力はできる（データを人質にしない）
- ライセンスキーは ECDSA P-256 署名付き（`PCP1.<内容>.<署名>`）。公開鍵だけをアプリに入れ、
  サーバーなしで端末内で検証する。署名用の秘密鍵は販売者の手元のみ
- 月額プランは、支払い済み期間の末日（＋猶予数日）を有効期限としてキーを毎月発行する

## 4. 非機能要件
- 無料版と同じ（オフライン動作、iPhone 片手操作、セーフエリア対応など）
- 無料版と同じオリジンでも干渉しない（IndexedDB 名・localStorage 接頭辞・キャッシュ名を分離）

## 5. 今回の対象外 / 今後の候補
- 決済と自動キー発行（Stripe Webhook などのサーバー処理が必要）
- クラウド同期・チーム共有
- ねじのインチ規格、はすば歯車、任意エッジのフィレット
