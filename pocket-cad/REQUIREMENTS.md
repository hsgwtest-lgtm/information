# Pocket CAD 要件定義

出先の iPhone から 3D プリント用のモデルを作成し、STL で保存できる PWA。
GitHub Pages で配信し、ホーム画面に追加してネイティブアプリのように使う。

## 1. 想定ユーザーと利用シーン

- 3D プリンター（FDM）を日常的に使う個人
- 出先（電車・カフェ等）で思いついた治具・ケース・ブラケット・小物を iPhone で作り、
  帰宅後すぐスライサーに渡したい
- 回線が不安定・オフラインでも作業できること

## 2. 動作環境

| 項目 | 要件 |
| --- | --- |
| 主対象 | iPhone / iPad の Safari（iOS 16.4 以降）、ホーム画面に追加した PWA |
| その他 | Android Chrome、PC 版 Chrome / Safari / Edge でも動作 |
| 配信 | GitHub Pages（静的ファイルのみ、ビルド不要） |
| 通信 | 初回読み込み後は完全オフラインで動作（外部 CDN に依存しない） |

## 3. 機能要件

### 3.1 モデリング（必須）

- **単位は mm、Z 軸が上**（スライサーと同じ座標系）
- 基本形状: 直方体（角丸可）、円柱、円錐、球、トーラス、パイプ、多角柱、くさび、
  テキスト（英数字）
- **スケッチ押し出し**: 2D 画面で多角形を描き、高さを指定して立体化
- **回転体**: 2D 断面を Z 軸まわりに回転して立体化
- 各オブジェクトを **ソリッド / 穴** に切り替え可能
- **グループ化 = ブーリアン演算**: ソリッドは結合、穴は削り取り。
  「交差」モードも選択可。グループ解除で元の部品に戻せる（非破壊）
- 数値入力による位置・回転・寸法の正確な指定（± ステッパー付き）
- タッチ操作: 1 本指で視点回転、2 本指でズーム・パン、
  選択中オブジェクトをドラッグで移動（XY 平面 / Z 方向切り替え）
- スナップ（0.1 / 0.5 / 1 / 5 / 10 mm）
- 複製、削除、ミラー（X/Y/Z）、床に置く、中央へ移動
- 整列（複数選択時、X/Y/Z 各軸の最小・中央・最大）
- 配列複製（直線配列・円形配列）
- 元に戻す / やり直し（100 段階）
- STL 読み込み（既存モデルの加工用、バイナリ / ASCII）

### 3.2 出力（必須）

- **バイナリ STL で保存**（全体 / 選択中のみ）
- iOS では共有シートから「ファイルに保存」や AirDrop、他アプリへ送信
- 出力前に寸法・体積・推定重量（PLA 等の密度から）を表示

### 3.3 プロジェクト管理

- 端末内（IndexedDB）に自動保存、複数プロジェクトの一覧・新規・複製・名前変更・削除
- プロジェクトファイル（.json）の書き出し / 読み込み（端末間の受け渡し・バックアップ）

### 3.4 表示

- 造形エリア（ビルドプレート）の表示。サイズは設定で変更（初期値 220×220×250 mm）
- 造形エリアからはみ出したオブジェクトを警告表示
- 視点プリセット（全体表示、上、正面、右、斜め）

## 4. 非機能要件

- 片手で操作できるよう主要操作は画面下部に配置、タップ領域は 44pt 以上
- 数値入力時に画面がズームしない（入力欄 16px 以上）
- ノッチ / ホームインジケータのセーフエリア対応
- ダーク UI（屋外・夜間の視認性）
- ブーリアン演算はスマートフォンで数百 ms 以内（three-bvh-csg を使用）
- 形状計算結果をキャッシュし、移動だけなら再計算しない

## 5. 対象外（今回はやらない）

- フィレット / 面取りの任意エッジ指定（直方体の角丸のみ対応）
- 日本語テキスト（フォントが大きいため。英数字のみ）
- クラウド同期（プロジェクトファイルの書き出しで代替）
- 3MF / OBJ 出力

## 6. 技術構成

| 層 | 採用 |
| --- | --- |
| 3D 描画 | three.js r180（`vendor/vendor.js` に同梱） |
| ブーリアン | three-bvh-csg + three-mesh-bvh（同上） |
| UI | 素の HTML / CSS / ES Modules（フレームワークなし） |
| 保存 | IndexedDB |
| オフライン | Service Worker（キャッシュファースト） |

`vendor/vendor.js` は `tools/build-vendor.sh` で再生成できる（esbuild でバンドル）。
