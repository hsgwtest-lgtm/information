立体地図工房（GitHub Pages 版）

このフォルダをそのまま GitHub のリポジトリに入れ、GitHub Pages で公開すると使えます。
例：hsgwtest-lgtm/information リポジトリに rittai-chizu フォルダとして置く
　→ https://hsgwtest-lgtm.github.io/information/rittai-chizu/

・地名や住所で探すと、日本中どこでも立体地図と光るランプのSTLを作れます。
・標高：国土地理院 標高タイル（dem_png）、地名検索：国土地理院、道と建物：OpenStreetMap（Overpass API）
・STLはZIPにまとめて保存されます（立体地図／ランプのパネル・箱・ふた、印刷の設定メモ）。
・ホーム画面に追加するとアプリとして起動できます（PWA）。

販売に使うときの出典表示の例：
「標高データ：国土地理院」「地図データ：© OpenStreetMap contributors」
