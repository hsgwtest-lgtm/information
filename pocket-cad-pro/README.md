# Pocket CAD Pro

iPhone で使える 3D プリント用モデリング PWA。無料版 [Pocket CAD](../pocket-cad/) の全機能に、
最適化・設計・印刷準備のツールを加えたものです。**すべての機能を最初から使えます**（課金・ライセンスキー・お試し期間はありません）。
要件は [REQUIREMENTS.md](REQUIREMENTS.md) を参照。

公開 URL（GitHub Pages）: https://hsgwtest-lgtm.github.io/information/pocket-cad-pro/

## 形を整える・作る（v1.3 で追加）

| 機能 | 内容 |
| --- | --- |
| 辺・面の選択 | 部品を選んで「辺・面」。ブーリアンで作った部品でも、辺（円の縁も 1 本として）や平らな面をタップで選べる |
| 辺の丸め・面取り | 選んだ辺にフィレット（R）・面取り（C）。へこんだ辺は肉を盛る（付け根の補強）。3 本の辺が直角に集まる角は球面でつなぐ。大きさは後からパネルで変更でき、上限も表示 |
| 面の押し出し | 選んだ平らな面を垂直に押し出す・へこませる（穴のあいた面は穴ごと） |
| シェル（中空化） | 壁の厚みを指定して中をくり抜く。開ける面を選べば容器・カバーに。外側の形はそのまま |
| 格子化 | 表面ボロノイ（網目の殻）・立体ボロノイ（骨組み）・ジャイロイド（外皮あり / なし）。プレビューで重さ・三角形数を確認。後から設定を変えて作り直せる |
| サポートレス化 | 今の向きで、横穴をティアドロップに・張り出しの下に 45° の補強・底の辺の面取り（エレファントフット対策）。サポートが必要な面積の変化を表示 |
| 写真で採寸 | A4 などの紙に物を置いて真上から撮ると、紙の 4 隅で遠近を補正して実寸で輪郭を取る。ぴったりトレー（指の切り欠き付き）・型板・輪郭の形を作る |
| スナップフィット設計 | 片持ちばりのフック＋受けの窓。材料ごとの許容ひずみで割れないか判定し、はめる力・外す力を表示。足りなければ必要な腕の長さを提案 |
| 蝶番（そのまま動く） | 組み立て不要で一度に印刷できる蝶番のテンプレート（円すいピン、すき間指定） |

入口: 部品を選択したときの「辺・面」「シェル」「格子化」「サポートレス」ボタン、下のパネルの「設計ツール」、右上の「ツール」ボタン。

## 最適化（v1.2 で追加）

| 機能 | 内容 |
| --- | --- |
| 形状の最適化（トポロジー最適化） | 設計領域に固定（ネジ穴・辺）と荷重を置くと、力の伝わらない材料を削った軽くて強い形を自動で作る。計算の様子をリアルタイムに表示し、重さ・たわみ・応力の目安と応力分布を表示。結果はネジ穴が正確な円の、編集できる部品になる |
| 向きの最適化 | 平らな面を下にする向き・6 方向・その間の方向など数十通りを比較。サポート量（部品の上に立つ分も含む）・印刷時間・接地面積から候補を 3 つ、プレビュー付きで提示 |
| 自動配置（詰め込み） | 上から見た実際の形で、回転も使って造形エリアに詰める。L 字や丸い部品は箱で並べるより多く入る。配置図を事前に表示 |
| 敷き詰め | 選択した部品を造形エリアに入るだけ複製して並べる（入る個数を事前に表示） |

入口: 下のパネルの「設計ツール → 形状最適化」、右上の「ツール」ボタン（最適化の欄）、部品を選択したときの「向き最適化」「敷き詰め」ボタン。

## トポロジー最適化のしくみ

- 4 節点の平面応力要素（格子）・密度フィルター・OC 法による SIMP 法。定式化は Andreassen ほか
  「Efficient topology optimization in MATLAB using 88 lines of code」（2011）と同じ
- 連立方程式は、短い辺の方向に節点番号を振ってバンド幅を最小にしたバンドコレスキー分解で解く
- 検証: MATLAB 版 top88 の Python 移植と MBB はり（60×20 要素）で比べ、全 127 反復の
  コンプライアンスが相対誤差 1e-10 で一致
- 計算の細かさ「速い / 標準 / 細かい」= 約 2,400 / 4,800 / 8,000 要素。直近 5 回の改善が 0.25% 未満になったら終了
- 形は密度 0.5 の等値線（マーチングスクエア）を平滑化して押し出す。ネジ穴とその周りの肉は正確な円柱に置き換える
- たわみ・応力は、0.5 で二値化した形を印刷品の一般的な物性（PLA: 縦弾性係数 2.3 GPa など）で解き直した目安。
  材料は「設定」の材料に合わせる

## 辺の丸めと格子化のしくみ

- 辺・面の認識: ブーリアンの結果は同じ辺が両側で別々に分割されている（T 字の継ぎ目）ため、頂点を許容差で
  まとめ、同一平面の三角形を「面」にまとめ、継ぎ目の相手の面を形から探して折れ目（30° 以上）を求める。
  なめらかにつながる線分（円の 64 辺など）は 1 本の辺にまとめる
- 丸め・面取り: 辺に沿って断面（円弧 / 斜め線）を掃引した立体を、出っ張った辺なら削り、へこんだ辺なら足す。
  円弧は半径の 0.5% だけ大きく描き、面に接するのではなく浅い角度（約 6°）で切り込ませる（接するだけの面は
  ブーリアンで細い破片を生むため）。3 本の辺が集まる角は、各辺の掃引を角の手前で止め、その端の点をそのまま
  縁に使う球面パッチでつないだ 1 つの閉じた立体にする
- ブーリアン結果の後処理: 元の立体の外枠からはみ出した三角形（数値誤差の破片）と面積 0 の三角形を除く
- 格子化・シェル: 部品をボクセル化し、境界の近くだけ BVH で正確な距離を求めた距離場に、ボロノイ（種点は
  ポアソン円板サンプリング）・ジャイロイド・内側のオフセットを組み合わせ、サーフェスネッツで閉じたメッシュにする。
  計算は Web Worker。シェルは外側を元の正確な形のまま残し、内側の立体だけを引く

## 構成（無料版からの追加分）

```
js/pro/topology.js       形状の最適化の画面（設計領域・固定・荷重の編集、実行、部品の作成）
js/pro/topopt.js         SIMP 法の計算（有限要素・密度フィルター・OC 法・評価・輪郭抽出）
js/pro/topopt-worker.js  上の計算を Web Worker で実行
js/pro/orient.js         向きの最適化（候補の生成・サポート体積・プレビュー）
js/pro/nest.js           自動配置（詰め込み）・敷き詰め
js/pro/features.js       各種ツールの画面と操作
js/pro/threads.js        ISO メートルねじの形状生成
js/pro/gear.js           インボリュート歯車の輪郭
js/pro/trace.js          画像・文字・SVG → 輪郭
js/pro/lithophane.js     写真 → リトフェイン
js/pro/analysis.js       オーバーハング・印刷見積もり
js/pro/export3mf.js      3MF / OBJ 出力（ZIP 作成含む）
js/pro/advanced.js       テンプレート画面・分割・パターン穴・面に配置・マイパーツ・共有リンク・変数・プリンター
js/pro/templates.js      パラメトリックテンプレート 10 種（蝶番を含む）
js/pro/loft.js           面取り箱・Gridfinity ベースの形状
js/pro/pattern.js        ハニカムなどの穴配置
js/pro/drawing.js        三面図（SVG）
js/pro/edges.js          ブーリアン結果の輪郭線抽出（継ぎ目線を除去）
js/pro/edgeops.js        辺・面の認識、丸め・面取りの立体（角の球面つなぎ含む）
js/pro/edgetools.js      辺の丸め・面の押し出しを部品（グループ）にする
js/pro/subsel.js         辺・面の選択（ビューでのタップ、ツールバー、ダイアログ）
js/pro/sdf.js            距離場・ボロノイ / ジャイロイド・シェル・サーフェスネッツ
js/pro/sdf-worker.js     上の計算を Web Worker で実行
js/pro/lattice.js        格子化・シェルの画面
js/pro/printfix.js       サポートレス化（ティアドロップ・45° 補強・底の面取り）
js/pro/photofit.js       写真で採寸（紙の検出・射影変換・輪郭 → トレー / 型板）
js/pro/snapfit.js        スナップフィットの計算と形
```

ファイルを変えたら `sw.js` の `VERSION` を上げてください（オフライン用キャッシュの更新）。

無料版とは別のデータベース（`pocket-cad-pro`）とキャッシュ（`pcpro-*`）を使うため、
同じ端末で両方をインストールしても干渉しません。
